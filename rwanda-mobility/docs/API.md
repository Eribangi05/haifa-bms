# API reference

> Generated by `npm run docs` from the registered routes. Base path `/api/v1`. JSON in/out. Errors: `{ "error": { "code", "message", "details" } }`.
> Auth: `Authorization: Bearer <access token>`. State-changing booking/payment calls accept an `Idempotency-Key` header. Interactive details live in the zod schemas next to each route (`src/routes/*.ts`).
